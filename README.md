## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/siabang35/seniquwebapp.git

# Install dependencies (Root)
npm install

# Setup Frontend
cd frontend
npm install
npm run dev

# Setup Backend
cd backend
npm install
npm run start:dev
```

## 🌟 Project Overview

Seniqu is a bridge between traditional fine art and the digital web3 world, offering:
- **Virtual Museums**: Immersive digital galleries for institutions.
- **NFT Marketplace**: Secure trading of digital assets.
- **Community Hub**: Forums and social features for art enthusiasts.
- **AI Integration**: Tools for curation, appraisal, and discovery.
- **Comprehensive Dashboards**: Tailored experiences for Artists, Collectors, Institutions, and Admins.
